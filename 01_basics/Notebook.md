# 基本文法ノート

このレッスンでは、PythonやC言語の経験を生かして、C++の基本的な書き方を学びます。
実際に動くコードは [main.cpp](main.cpp) にあります。

## 範囲for文

### 基本形

C++には、コンテナの要素を先頭から順番に処理する**範囲for文**があります。
C++11で追加された機能で、Pythonの`for item in items`に近い書き方です。

```cpp
std::vector<int> numbers = {1, 2, 3, 4, 5};

for (int number : numbers) {
    std::cout << number << " ";
}
```

このコードは、次のように読むことができます。

> `numbers`から要素を1つずつ取り出し、その値を`number`として処理する

一般的な形は次のとおりです。

```cpp
for (要素を受け取る変数 : 繰り返し対象) {
    // 1要素に対する処理
}
```

`:`は「範囲の中から順番に取り出す」という意味です。条件を書く記号ではありません。

### C言語風のfor文との違い

添字を使うC言語風のfor文では、次のように書きます。

```cpp
for (std::size_t i = 0; i < numbers.size(); ++i) {
    std::cout << numbers[i] << " ";
}
```

範囲for文では、添字`i`や要素数`numbers.size()`を自分で管理する必要がありません。
そのため、単に「全要素を順番に処理したい」場合は、範囲for文のほうが短く、範囲外アクセスも起こしにくくなります。

一方、次のような処理では添字を使うfor文が必要になることがあります。

- 要素番号を使いたい
- 前後の要素を同時に参照したい
- 2つの配列を同じ添字で処理したい

### 変数の型と要素のコピー

`std::vector<int>`の各要素は`int`なので、次の`number`も`int`です。

```cpp
for (int number : numbers) {
    // numberはnumbersの要素のコピー
}
```

この場合、`number`を変更しても`numbers`の要素は変わりません。

```cpp
for (int number : numbers) {
    number *= 2;
}
// numbersは変わらない
```

### 参照を使って要素を変更する

元のコンテナの要素を変更したい場合は、変数を参照として宣言します。

```cpp
for (int& number : numbers) {
    number *= 2;
}
```

`int& number`は、要素のコピーではなく、元の要素そのものを別名で扱います。
そのため、この例では`numbers`の各要素が2倍になります。

参照については、このファイルの後半にある「参照（Reference）」の説明も確認してください。

### 読み取り専用にする

要素を読むだけで、変更させたくない場合は`const`を付けられます。

```cpp
for (const int& number : numbers) {
    std::cout << number << " ";
}
```

`const int&`には、次の2つの意味があります。

- `&`: 要素をコピーせず、元の要素を参照する
- `const`: その参照を通して要素を変更しない

`int`のような小さな型ではコピーのコストは小さいため、まずは`int number`で理解すれば十分です。
大きなオブジェクトや`std::string`などでは、読み取り専用の`const T&`がよく使われます。

### `auto`を使う書き方

要素の型をコンテナから推論させることもできます。

```cpp
for (const auto& number : numbers) {
    std::cout << number << " ";
}
```

この場合、`auto`は`int`として推論されます。
ただし、`auto`は便利な反面、型の理解が曖昧な段階では明示的な型で書くほうが読みやすいこともあります。

### ポインタを要素にする場合

後のOOPレッスンでは、`std::vector<Animal*>`のようにポインタを格納したコンテナも扱います。

```cpp
for (const Animal* animal : zoo) {
    animal->introduce();
    animal->speak();
}
```

ここでも考え方は同じで、`zoo`から要素を1つずつ取り出しています。
ただし、取り出した要素がポインタなので、メンバ関数を呼ぶときは`.`ではなく`->`を使います。

```cpp
animal->speak();
// (*animal).speak(); と同じ意味
```

`const Animal*`は「このポインタを通して`Animal`の内容を変更しない」という意味です。
ポインタを使った多態性については、[02_2_oop](../02_2_oop)で詳しく学びます。

## このレッスンのまとめ

| 書き方 | 意味 |
| --- | --- |
| `for (int number : numbers)` | 要素を値として受け取る。要素はコピーされる |
| `for (int& number : numbers)` | 元の要素を参照し、変更できる |
| `for (const int& number : numbers)` | コピーせずに読み取る。変更はできない |
| `for (const auto& number : numbers)` | 要素の型を推論し、コピーせずに読み取る |

まずは「範囲for文は、コンテナから要素を1つずつ取り出す構文」と覚えれば十分です。
その後、値・参照・`const`の違いを、要素を変更する必要があるかどうかで使い分けます。
